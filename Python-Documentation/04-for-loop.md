# Python For Loop — Complete Reference

> The `for` loop is used to repeatedly execute a block of code for each item in an iterable such as a list, tuple, string, dictionary, set, or a sequence generated by `range()`.

---

## What is a `for` Loop?

A `for` loop allows Python to process multiple values one by one without writing the same code repeatedly.

### Basic Syntax

```python
for variable in iterable:
    statement
```

Example:

```python
services = ["web", "api", "database"]

for service in services:
    print(service)
```

Output:

```text
web
api
database
```

### Execution Flow

```text
Iterable
   |
   v
Get first item
   |
   v
Execute loop body
   |
   v
Get next item
   |
   v
Execute loop body
   |
   v
Continue until no items remain
```

---

## What is an Iterable?

An **iterable** is an object whose values can be processed one by one.

Common Python iterables include:

| Iterable | Example |
|---|---|
| List | `[10, 20, 30]` |
| Tuple | `(10, 20, 30)` |
| String | `"Python"` |
| Dictionary | `{"name": "app", "port": 8080}` |
| Set | `{10, 20, 30}` |
| `range()` | `range(1, 6)` |

## Loop Variable

The variable after `for` is called the **loop variable**.

```python
services = ["web", "api", "database"]

for service in services:
    print(service)
```

Here:

```text
service  -> loop variable
services -> iterable
```

During each iteration:

```text
Iteration 1 -> service = "web"
Iteration 2 -> service = "api"
Iteration 3 -> service = "database"
```

The loop variable receives one item at a time.

## `range()` Function

`range()` generates a sequence of numbers that can be used with a `for` loop.

### Basic Syntax

```python
range(stop)
```

Example:

```python
for number in range(5):
    print(number)
```

Output:

```text
0
1
2
3
4
```

### Important

The `stop` value is **not included**.

Therefore:

```python
range(5)
```

generates:

```text
0, 1, 2, 3, 4
```

not:

```text
0, 1, 2, 3, 4, 5
```

---

## `range(start, stop)`

The two-argument form specifies where the sequence starts and where it stops.

### Syntax

```python
range(start, stop)
```

Example:

```python
for number in range(1, 6):
    print(number)
```

Output:

```text
1
2
3
4
5
```

The `stop` value `6` is excluded.

### Formula

```text
start <= value < stop
```

Therefore:

```python
range(1, 6)
```

means:

```text
1 <= value < 6
```

---

## `range(start, stop, step)`

The three-argument form allows the increment to be specified.

### Syntax

```python
range(start, stop, step)
```

Example:

```python
for number in range(1, 11, 2):
    print(number)
```

Output:

```text
1
3
5
7
9
```

Here:

```text
start = 1
stop  = 11
step  = 2
```

---

## Understanding `range()` Arguments

| Syntax | Meaning |
|---|---|
| `range(stop)` | Start from `0`, increment by `1` |
| `range(start, stop)` | Start from `start`, increment by `1` |
| `range(start, stop, step)` | Start from `start`, use specified step |

Examples:

```python
range(5)
```

```text
0 1 2 3 4
```

```python
range(2, 6)
```

```text
2 3 4 5
```

```python
range(2, 10, 2)
```

```text
2 4 6 8
```

## Why Does `range()` Start at `0`?

When only one argument is provided:

```python

```

Python uses:

```text
start = 0
stop  = 5
step  = 1
```

Therefore:

```text
0
1
2
3
4
```

This is useful when working with indexes.

## `range()` for Processing a Known Number of Items

Suppose there are five items to process.

```python
for number in range(1, 6):
    print(number)
```

Output:

```text

2
3
4
5
```

The `+1` is commonly required when the desired ending value should be included.

For example:

```python
count = 5

for number in range(1, count + 1):
    print(number)
```

Output:

```text

2
```

Without `+1`:

```python
range(1, count)
```

produces:

```text

2
3
4
```

## `range()` Does Not Represent an Index Automatically

Consider:

```python
for number in range(1, 6):
    print(number)
```

The value `1` is simply the first number generated by `range()`.

It is not automatically an index.

If you use:

```python
for index in range(5):
    print(index)
```

then the values:

```text
0
1
2
3
4
```

can represent indexes because Python sequences use zero-based indexing.

The meaning depends on how the programmer uses the value.

## Iterating Directly vs Using Indexes

If you only need the values, iterate directly over the collection.



```text

2 database
```

## `break` Statement

The `break` statement immediately terminates the loop.

### Example

```python
for number in range(1, 10):
    if number == 5:
        break

    print(number)
```

Output:

```text
1
2
3
4
```

When:

```python
number == 5
```

becomes `True`, the loop stops.

### Flow

```text
1 -> process
2 -> process
3 -> process
4 -> process
5 -> break
     |
     v
   Exit loop
```

## `continue` Statement

The `continue` statement skips the current iteration and moves to the next iteration.

Example:

```python
for number in range(1, 6):
    if number == 3:
        continue

    print(number)
```

Output:

```text
1
2
4
5
```

When `number` is `3`, the remaining statements in that iteration are skipped.

### Flow

```text
Iteration
    |
    v
Condition?
    |
  True
    |
    v
continue
    |
    v
Next iteration
```

---

## `break` vs `continue`

| Statement | Behavior |
|---|---|
| `break` | Terminates the entire loop |
| `continue` | Skips the current iteration |
| Neither | Continues normally |

Example:

```python
for number in range(1, 6):

    if number == 3:
        continue

    if number == 5:
        break

    print(number)
```

## Nested `for` Loops

A `for` loop can contain another `for` loop.


```text
   |     +-- Inner 3

   +-- Outer 3
         |
         +-- Inner 1
         +-- Inner 2
```

## `enumerate()`

`enumerate()` provides both the index and the value while iterating.

```python
services = ["web", "api", "database"]

for index, service in enumerate(services):
    print(index, service)
```

Output:

```text
0 web
1 api
2 database
```

A starting index can also be specified:

```python
for index, service in enumerate(services, start=1):
    print(index, service)
```

Output:

```text
1 web
2 api
3 database
```

### Why `enumerate()` is Useful

Instead of:

```python
for index in range(len(services)):
    print(index, services[index])
```

you can use:

```python
for index, service in enumerate(services):
    print(index, service)
```

This is generally clearer when both the index and value are required.

A counter can be updated during each iteration.


### Flow

```text

 |
```

## Counting Different Conditions

## Infinite Loop Consideration

A normal `for` loop over a finite iterable eventually ends.

For example:

```python
for number in range(1, 6):
    print(number)
```

terminates after five iterations.

The loop can also terminate earlier using:

```python
break
```

Be careful when generating or consuming data from potentially unbounded sources.

```python
    print(number)
```

### Wrong `range()` Boundary

Incorrect when `5` must be included:

```python

```

Correct:

```python

```

---

### Wrong Step Direction

This does not generate the expected descending sequence:


```python

```

### Modifying a Collection While Iterating

Avoid directly changing the structure of a collection while iterating over it unless the behavior is well understood.

Prefer creating a new collection or iterating over a copy when modification is required.

## `for` Loop vs `while` Loop

| Feature | `for` | `while` |
|---|---|---|
| Main purpose | Iterate over an iterable | Repeat while condition is true |
| Typical use | Collections and known sequences | Condition-based repetition |
| Automatic progression | Yes | Programmer controls it |
| Common termination | Iterable exhausted | Condition becomes false |
| Counter required | Not always | Often required |
| Example | `for item in items:` | `while count < 5:` |

### `for` Example

```python
for number in range(5):
    print(number)
```

### `while` Example

```python
count = 0

while count < 5:
    print(count)
    count += 1
```

---

## Choosing the Correct Loop

Use a `for` loop when:

```text
You have a collection
       OR
You have a known sequence
       OR
You want to iterate a known number of times
```

Use a `while` loop when:

```text
You want to continue while a condition remains True
```

## Best Practices

- Use descriptive loop variable names.
- Iterate directly over a collection when indexes are not required.
- Use `enumerate()` when both index and value are needed.
- Use `zip()` when processing multiple collections in parallel.
- Remember that `range()` excludes its `stop` value.
- Use `break` when the loop should terminate immediately.
- Use `continue` when only the current iteration should be skipped.
- Keep nested loops simple and readable.
- Avoid unnecessary index-based loops.
- Use `range()` when a numeric sequence or iteration count is required.
- Keep the loop body focused on one logical operation.
- Avoid modifying a collection while directly iterating over it.
- Use counters and accumulators when collecting results across iterations.
- Use conditions inside loops to filter or classify items.
- Choose `for` when working with an iterable or a known sequence.

- The variable after `for` is the loop variable.
- Lists, tuples, strings, sets, dictionaries, and `range()` can be iterated.
- `range()` generates a sequence of numbers.
- `range()` excludes the `stop` value.
- `range(5)` generates `0` through `4`.
- `range(1, 6)` generates `1` through `5`.
- `range()` can use a positive or negative step.
- A loop variable is not automatically an index.
- Python indexes normally start at `0`.
- Use direct iteration when only values are required.
- Use `enumerate()` when both index and value are required.
- Use `zip()` when multiple collections need to be processed together.
- `break` terminates the loop.
- `continue` skips the current iteration.
- A `for` loop can contain `if`, `elif`, and `else` conditions.
- Nested `for` loops allow multiple levels of iteration.
- Counters and accumulators can collect information during a loop.
- `for` loops are fundamental to Python automation and DevOps scripting.
